# Definition of Done

- Scope matches a GitHub Issue.
- Acceptance criteria are measurable and verified.
- Relevant automated checks and manual checks are recorded.
- Existing behavior was preserved unless evidence justified a change.
- User-facing or architectural behavior has updated documentation.
- A work log exists at `docs/logs/YYYY-MM/ISSUE-<ID>-<slug>.md`.
- Public content contains no confidential business or personal research data.
- Draft PR was self-reviewed and linked to the Issue.
- Project owner review is still required before merge.
