# Private project fields and views

The full launch control plane belongs in the private GitHub Project `DrivingSupport Launch 2026`. Do not duplicate confidential schedules or commercial assumptions in this public repository.

## Required fields

Status: Backlog, Ready, In Progress, In Review, Ready to Merge, Done, Blocked
Decision: Draft, Awaiting GO, GO, HOLD
Phase: P0 Governance, P1 MVP, P2 Skills, P3 Pilot, P4 Dashboard, P5 B2B
Priority: P0, P1, P2, P3
Workstream: Product, Vision, Simulation, Content, Research, BizDev, Infra, Docs
Risk: Low, Medium, High
Effort: 1, 2, 3, 5, 8

Also add Start Date, Target Date, Success Metric, Owner, and a weekly Iteration field if supported.

## Intended views

- `01 Command Center`: table with Status, Decision, Phase, Priority, Risk, Owner, Target Date.
- `02 Delivery Board`: board grouped by Status.
- `03 12-Week Roadmap`: roadmap using Start Date and Target Date.

If the installed GitHub CLI cannot create custom fields or saved layouts, configure these in the private Project UI: Project settings → Fields → New field, then Views → New view. Keep the Project private and place confidential business items there as draft items rather than public repository Issues.
